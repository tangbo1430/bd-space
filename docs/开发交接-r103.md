## 本地运行与复核

项目为 Astro 5 静态站，使用 TypeScript、原生 CSS 和 Playwright。仓库 README 指定 Node.js 24，`package.json` 固定 pnpm 11.19.0。以下命令从开发工作树根目录运行。

```powershell
pnpm install --frozen-lockfile
pnpm dev --host 127.0.0.1
```

准备预览站构建时，先提交准备发布的源码，以便版本文件记录正确的 Git 提交。按下面的顺序执行，每步成功再继续。资源裁剪只针对生成目录 `dist/`。

```powershell
pnpm test
$env:PUBLIC_SITE_URL = 'http://23.251.34.150:8080'
pnpm build
pnpm package:assets
pnpm verify
pnpm audit:assets
pnpm audit:translations
pnpm exec astro preview --host 127.0.0.1 --port 4389
```

另开终端，在同一工作树内运行专项复核。UI 脚本使用本机 Microsoft Edge，扫描件脚本使用 Python、Pillow 和上文的原稿目录。`verify_paper.py local` 会比对构建后的 70 张报告与 70 张缩略图；`ui.mjs` 会在中文资质页面打开报告，并在中英文产品页实测目录比例和视频播放。第二个参数用新的标签保存截图，便于与上次结果对照。

```powershell
python artifacts/r103-release/verify_paper.py local
node artifacts/r103-release/ui.mjs http://127.0.0.1:4389 handoff
```

r103 当次记录为 43 个构建页面、50 个单元测试通过、68 项公网 HTML 与资源校验通过。页面验收还要看加载完成后的浏览器画面。若只验证文件存在、页数或哈希，透明层处理错误也可能通过。可优先打开这三个位置。[检测报告](http://23.251.34.150:8080/zh/qualifications/?v=r103#reports) · [4S 目录封面](http://23.251.34.150:8080/zh/products/?v=r103#model-4s) · [诗诺安装视频](http://23.251.34.150:8080/zh/products/snow11/?v=r103#installation-video)

## 预览发布与回退

1. 发布前读取公网 `/version.json`，核对现网提交和上一版 `manifest.json`。页面链接里的 `?v=r103` 只是查询参数，真实版本由 `version.json` 给出。
2. 最近一版打包过程在 `artifacts/r103-release/prepare.py`。它针对 r102 → r103 写死了基线、版本名、提交和容器名。下次发布要在新的发布目录里生成对应版本脚本，以 r103 的清单计算变更及删除项；保留 r103 档案供回退。
3. 预览服务器使用本机 SSH 别名 `hw-php-cvm`。每版单独建 `/opt/banda-space-preview/releases/<版本>-<短提交>/site`，上传该版的 `delta.tar.gz`、`manifest.json`、`removed.json`、`preview.Caddyfile` 和 `publish.sh`。脚本先重建并核对完整站点，在本机端口 18080 试跑，再切换对外端口 8080 的 `banda-space-preview` 容器。
4. 切换后检查公网版本、变更资源与相关页面，并在公网上重跑本次改动的浏览器测试。r103 的公开版本核验脚本为 `artifacts/r103-release/verify.py`，专门断言 r103 提交。
5. r103 服务器目录为 `/opt/banda-space-preview/releases/r103-d564ce0/`。其 `rollback.sh` 用于从 r103 退回 r102（`46188fb`）。如需回退，先核对当前活动版本，再使用该次发布生成的回退脚本。
